promptpageco — Maroon AI workspace

Chat, vibe-code websites, create files, and work with GitHub or GitLab.

Supabase setup needed

Add a public config.js file beside index.html with the two public Supabase values. Never put model API keys or a Supabase service-role key in this file.

window.PROMPTPAGECO_CONFIG = {
  supabaseUrl: "your-project-url",
  supabaseAnonKey: "your-publishable-or-anon-key"
};

The app will still show the AI workspace, but login and saved chat memory stay disabled until Supabase is configured.
